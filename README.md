# DateTimeClipper

アナログ時計・デジタル時計をデスクトップに常駐表示し、クリックひとつで日付や定型文字列をクリップボードへコピーできる Windows 用の常駐アプリです。

![platform](https://img.shields.io/badge/platform-Windows%2010%2F11-0078D6)
![.NET](https://img.shields.io/badge/.NET-8.0-512BD4)
![license](https://img.shields.io/badge/license-MIT-green)

- **時計**: アナログ / デジタル / 両方（横並び）を切り替え表示。枠なしの浮遊ウィンドウ。
- **コピー**: 時計をクリックすると日付・定型文の一覧が開き、選んだ文字列をクリップボードへコピー。
- **自由な見た目**: 文字色・時計色・背景色と、それぞれの不透明度をスライダーでリアルタイム調整。

> 「今日の日付を決まった書式で貼りたい」「よく使う定型文をすぐ貼りたい」を、常に見えている時計から1クリックで。

## 主な機能

- アナログ / デジタル / 両方（横並び）の表示切り替え
- デジタルは日付行・時刻行の書式を自由に設定（空欄にした行は非表示）
- 時計クリックでコピー一覧をポップアップ表示 → 項目クリックでクリップボードへコピー
- コピー項目は `{...}` テンプレート方式（例: `{yyyy/MM/dd}`、`本日`、`backup_{yyyyMMdd}.zip`）
- 和暦・ISO8601・Unix時間などの独自キーワードに対応
- 設定画面に**フォーマット早見表**（クリックで編集欄に書式を挿入）
- 枠なしウィンドウをどこを掴んでもドラッグ移動、端のドラッグでサイズ変更
- テーマプリセット4種（ダーク / ライト / 半透明ダーク / 完全透明）
- 常に最前面表示（他アプリの背後に隠れても自動で復帰）
- クリック透過（時計を背景化して下のアプリを操作可能に）
- マルチモニタ対応（メニューやコピー一覧は時計のあるモニタに表示）
- タスクトレイ常駐（表示/非表示・設定・クリック透過・終了）、多重起動防止
- 設定は `%APPDATA%\DateTimeClipper\config.json` に自動保存

## 動作環境

- Windows 10 / 11
- [.NET 8 デスクトップ ランタイム](https://dotnet.microsoft.com/download/dotnet/8.0)（自己完結型の配布物を使う場合は不要）

## インストール

[Releases](../../releases) から zip をダウンロードして展開し、`DateTimeClipper.exe` を起動します。

ソースからビルドする場合は下記「[ソースからビルド](#ソースからビルド)」を参照してください。

## 使い方

起動するとデスクトップに時計が表示され、タスクトレイに黄色い時計アイコンが常駐します。

| 操作 | 動作 |
|------|------|
| ウィンドウをドラッグ | 移動（どこを掴んでもOK） |
| ウィンドウの端をドラッグ | サイズ変更 |
| **左クリック** | コピー一覧を表示 → 項目クリックでコピー |
| **右クリック** | メニュー（設定 / 非表示 / 終了） |
| マウスを乗せる | 設定（⚙）ボタンを表示 |
| トレイアイコン左クリック | 時計の表示 / 非表示 |
| トレイアイコン右クリック | 表示切替 / 設定 / クリック透過 / 終了 |

### コピー項目の書式

コピー項目は1本のテンプレート文字列です。`{ }` の中だけが日時として展開され、それ以外はそのままの文字列になります。

| 入力例 | コピーされる文字列 |
|--------|--------------------|
| `{yyyy/MM/dd}` | `2026/07/08` |
| `{yyyyMMdd}` | `20260708` |
| `本日` | `本日`（固定文字列） |
| `backup_{yyyyMMdd_HHmmss}.zip` | `backup_20260708_100845.zip`（混在も可） |

`{ }` の中では .NET 標準の日時書式（`yyyy` `MM` `dd` `ddd` `HH` `mm` `ss` など）に加え、次の独自キーワードが使えます。

| キーワード | 出力例 |
|-----------|--------|
| `ISO8601` | `2026-07-08T10:08:45+09:00` |
| `UnixTime` | `1783647...`（秒） |
| `UnixTimeMs` | `1783647...`（ミリ秒） |
| `Wareki` | `令和8年7月8日` |
| `WarekiShort` | `R8/7/8` |

設定画面の「コピー項目」タブには、これらの書式と現在時刻での出力例を並べた**早見表**があり、行をクリックすると編集中の欄に `{書式}` の形で挿入されます。

## 設定

設定は自動的に `%APPDATA%\DateTimeClipper\config.json` に保存されます（ウィンドウ位置・サイズも保存）。設定ファイルが壊れていた場合はデフォルト設定で起動し、壊れたファイルは `config.json.bak` に退避します。

## 自動起動

`Win + R` →  `shell:startup` で開くフォルダに `DateTimeClipper.exe` のショートカットを置くと、ログオン時に自動起動します。

## ソースからビルド

```powershell
dotnet build -c Release
.\src\DateTimeClipper\bin\Release\net8.0-windows\DateTimeClipper.exe
```

### テスト

```powershell
dotnet test
```

## 使用技術

C# / .NET 8 / WPF（コードビハインド方式）。タスクトレイは Windows Forms の `NotifyIcon` を利用。設定は `System.Text.Json` で保存。
